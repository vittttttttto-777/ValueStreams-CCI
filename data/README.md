# Данные

Исходная модель инструмента на 26.09.2026 — то же, что загружено в Supabase миграцией `20260926000002_vs_seed.sql`.

| Файл | Что внутри |
|---|---|
| `model.json` | вся модель одним файлом: функции, потоки, шаги, гипотезы состава функций, точки накала |
| `functions.csv` | справочник функций (25 функций, версия 25.09.2026) |
| `streams.csv` | пять потоков и закреплённые команды |
| `vsN_steps.csv` | шаги потока VSN в исходной последовательности |
| `vsN_roles.csv` | функции на шагах (гипотеза из свода анкет 17.09, роль `none`) |
| `hot_points.csv` | точки накала из свода анкет |

CSV в UTF-8 с BOM — открываются в Excel без проблем с кириллицей.
Текущее состояние после работы команд берите из Supabase (см. `supabase/queries.sql`).
