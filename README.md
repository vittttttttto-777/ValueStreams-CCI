# Потоки создания ценности · Coral Club

Автономное веб-приложение для стратегической сессии «Зоны ответственности».
Пять потоков создания ценности, их шаги, функции на шагах и роли
«владелец / помощник / претендент», закрепление ролей с метрикой и сроком,
карта связей, цепочка ценности, матрица «функция × поток» и реестр споров.

Статический сайт без сборки. Данные хранятся в Supabase:
у каждого потока свои таблицы, сводная матрица строится представлениями.

```
├── index.html                  приложение
├── config.js                   адрес и publishable-ключ Supabase
├── vendor/supabase.js          supabase-js 2.117.1 (MIT)
├── fonts/                      Suisse Int'l и Newton (дизайн-система Coral Club)
├── supabase/migrations/        схема и начальные данные
├── supabase/queries.sql        готовые запросы: матрица, споры, пересмотры
├── data/                       исходная модель в JSON и CSV
└── netlify.toml
```

## Структура базы

Все объекты начинаются с `vs`, чтобы не пересекаться с другими приложениями проекта.

**Справочники**

| Таблица | Содержимое |
|---|---|
| `vs_functions` | 25 функций (справочник 25.09.2026) и функции, добавленные на сессии (`is_custom`) |
| `vs_streams` | 5 потоков, команда трека, ценность, KPI, журнал правок шагов |
| `vs_hot_points` | точки накала из свода анкет 17.09.2026 |

**По каждому потоку** (`vs1` … `vs5`)

| Таблица | Содержимое |
|---|---|
| `vsN_steps` | шаги потока: порядок, название, результат, метрика владельца, срок закрепления, сменщик, заметка, история. Удалённый командой шаг получает `active = false` и может быть возвращён |
| `vsN_roles` | функции на шагах: `owner` владелец, `helper` помощник, `claimant` претендент, `none` участвует без роли. У шага не может быть двух владельцев |

| Поток | Команда |
|---|---|
| VS1 Развивать продуктовый портфель | CoralEVO |
| VS2 Формировать клиентский спрос | PrimeGrowth |
| VS3 Исполнять клиентский заказ | ITModel |
| VS4 Обеспечивать успех клиента | HealthOS |
| VS5 Развивать партнёрскую сеть | GrowthModel |

**Сводные представления** (обновляются сами, отдельно их заполнять не нужно)

| Представление | Что показывает |
|---|---|
| `vs_all_steps`, `vs_all_roles` | шаги и роли всех пяти потоков одной таблицей |
| `vs_step_status` | каждый шаг: владелец, помощники, претенденты, статус, метрика, просрочен ли пересмотр |
| `vs_matrix` | матрица «функция × поток»: сколько шагов функция ведёт, поддерживает, оспаривает |
| `vs_disputes` | реестр споров за владение |

## Установка с нуля (новый проект Supabase)

1. Supabase → SQL Editor → выполнить по порядку файлы из `supabase/migrations/`.
2. Project Settings → API Keys → скопировать Project URL и publishable key в `config.js`.

В текущем проекте `awwhrlenhqoreagzfymn` миграции уже выполнены, `config.js` заполнен.

## Публикация

**GitHub:**

```bash
git init && git add . && git commit -m "Потоки создания ценности"
git branch -M main
git remote add origin https://github.com/<аккаунт>/coral-value-streams.git
git push -u origin main
```

**Сайт по ссылке:** Netlify → Add new site → Import from GitHub → репозиторий →
Build command пусто, Publish directory `.` → Deploy. Каждый push обновляет сайт.
Либо GitHub Pages: Settings → Pages → `main` / `(root)`.

## Доступ

Редактировать доску может любой, у кого есть ссылка на сайт (роль `anon`).
Удалять шаги и функции из справочника через приложение нельзя, только снимать функции с шагов.
Для входа по паролю поставьте защиту сайта в Netlify (Site configuration → Access & security).

## Шрифты

Suisse Int'l и Newton — лицензионные шрифты дизайн-системы Coral Club.
Держите репозиторий приватным, пока не уточните условия лицензии.
Без папки `fonts/` приложение работает на Helvetica Neue / Arial.

## Что где менять

- Состав шагов, функции на шагах, роли — в самом приложении, всё пишется в базу.
- Справочник функций, команды потоков, тексты потоков — в таблицах `vs_functions` и `vs_streams`.
- Карта связей, критерии коммерческой готовности, обратные связи — в `index.html`.
