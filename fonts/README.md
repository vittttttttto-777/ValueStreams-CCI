# Шрифты

Suisse Int'l (© Swiss Typefaces) и Newton (© ParaType) взяты из внутренней дизайн-системы Coral Club 1.0.

Это лицензионные шрифты. Прежде чем публиковать репозиторий открыто, уточните у владельца лицензии,
покрывает ли она веб-использование и размещение файлов в публичном репозитории.
Если нет — держите репозиторий приватным или удалите папку `fonts/`:
приложение автоматически перейдёт на Helvetica Neue / Arial.
